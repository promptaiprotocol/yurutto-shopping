# ゆるっと買い物 🛒

献立の買い出しをラクにする、ブラウザで使える買い物リストです。

## 主な機能

- 🥕 よく買う食材をカテゴリ別テンプレートから追加
- 🍳 24種類の献立から必要な食材をまとめて追加
- 📖 全24メニューに初心者向け簡単レシピ
- 👤 1人分 / 👥 2人分のレシピ切替
- ⭐ 自由追加した商品もお気に入り登録
- 🏷️ 商品カテゴリをあとから変更
- ➕ 自分専用カテゴリを追加・名前変更・削除
- ✏️ 自由入力時にカテゴリを選択
- 📝 数量・メモを各項目に追加
- 同じ食材の重複を自動防止
- チェック済みは自動でリスト下部へ
- 🛒 買い出しモードで未購入だけ表示
- チェック済みだけ削除 / 全削除
- ？ アプリ内かんたん使い方ガイド
- 📄 `guide.html` の1枚使い方ガイド
- ブラウザ内に自動保存
- 外部API・ログイン・広告なし
- オフライン対応

## レシピについて

料理初心者向けに手順を短くした、このアプリ用のオリジナル簡単レシピです。
肉・魚・卵などは中心まで十分に加熱し、商品パッケージやご家庭の衛生ルールを優先してください。

## 保存について

買い物リスト、お気に入り、追加カテゴリはブラウザの `localStorage` に保存します。
ブラウザのサイトデータを削除すると保存内容も消えます。
