# ゆるっと買い物 🛒

献立の買い出しをラクにする、ブラウザで使える買い物リストです。

## 主な機能

- 🥕 よく買う食材をカテゴリ別テンプレートから追加
- 🍳 献立を選ぶと必要な食材をまとめて追加
- ⭐ よく買うものをお気に入り登録
- ✏️ 自由入力
- 同じ食材の重複を自動防止
- 📝 数量・メモを各項目に追加
- チェック済みは自動でリスト下部へ
- 🛒 買い出しモードで未購入だけ表示
- チェック済みだけ削除 / 全削除
- ブラウザ内に自動保存
- 外部API・ログイン・広告なし
- オフライン対応

## 保存について

買い物リストとお気に入りはブラウザの `localStorage` に保存します。
ブラウザのサイトデータを削除するとリストも消えます。
